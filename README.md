# MONEYSEND (moneysend.com)

Real-time money transfer fee & exchange rate comparison platform tailored for US (NY/NJ) expats, international students, and global remitters.

## Features
- **Multi-Language Engine**: Instant switching between Korean (`KR`) and English (`EN`).
- **Live Remittance Calculator**: Real-time payout calculations across Wise, Remitly, WireBarley, Western Union, Bank Wires, and OFX.
- **Transparent Fee Breakdown**: Clear metrics factoring fixed transaction fees, base mid-market exchange rates, applied provider rates, and hidden spread markups.
- **Remittance Guides**: In-depth articles covering transfer checklists, fee structures, and safety regulations for US to Korea remittances.
- **AEO & SEO Optimized**: Complete JSON-LD, OpenGraph, hreflang (`ko`/`en`), and canonical metadata.
